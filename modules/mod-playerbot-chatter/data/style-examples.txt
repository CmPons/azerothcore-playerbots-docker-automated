# mod-playerbot-chatter — style example lines (few-shot STYLE anchors)
#
# The chatter mod feeds a random handful of these lines to the local LLM as
# "match this tone and length (don't reuse the content)" anchors, on BOTH the
# ambient (self-initiated) and reactive (reply) paths. The goal is to pin the
# model's voice to how real players actually type in WotLK global/party/guild
# chat: short, casual, abbreviated, game-jargon-heavy, dry humor, some gripes.
#
# FORMAT: one example per line. Blank lines and lines starting with '#' are
# ignored. Put the MESSAGE only, no "Name:" prefix and no timestamp. Keep lines
# short and lowercase-casual — they are imitated literally in shape.
#
# These are NOT content the bot should repeat; they only shape tone/length.
# Avoid ad-style multi-line WTS/LFM blurbs here (we don't want bots spamming
# ads) and don't start a line with "anyone" (the prompt forbids that opener).
#
# LIVE-EDITABLE: this file is read at worldserver startup. Edit it and restart
# ac-worldserver to apply — no rebuild. If the file is missing/empty the mod
# falls back to its built-in list. Path is set by PlayerbotChatter.StyleExamplesFile.
#
# Drawn from a real WotLK private-server chat capture plus the module's original
# built-in flavor lines. Add more by pasting cleaned lines from your own logs.
